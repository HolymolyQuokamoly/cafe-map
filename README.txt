# ☕ 서울·경기 카페 상권 분석 지도

브이월드(V-World) 지도 API를 활용하여 서울특별시와 경기도의 카페 점포 현황을 시각화하고, 지역별 상권 특성을 분석하는 웹 기반 지도 서비스입니다.

## 📍 주요 기능

- **카페 점포 현황**: 서울·경기도 내 카페 점포 수 및 위치 표시
- **지역별 카페 밀집도**: 시군구별 카페 점포 수와 면적 대비 밀집도 비교
- **상업지역 내 카페 분포**: 상업지역에 위치한 카페의 분포 및 밀집도 분석 (서울 지역)
- **브랜드별 카페 점포 비중**: 주요 카페 브랜드의 지역별 점포 수 및 비중 분석

## 📊 데이터 기준

- **데이터 출처**: 소상공인시장진흥공단 상가(상권)정보
- **데이터 기준일**: 2026년 6월
- **분석 대상 지역**: 서울특별시 및 경기도
- **분석 대상 업종**: 카페 (업종 세분류 코드 I21201)

※ 일부 상업지역 분석에는 별도 시점의 도시계획 공간정보가 활용되며, 경기도의 실제 상업지역 내 카페 밀집도는 검증 대상입니다.

## 🗺️ 사용 기술

- HTML5 / CSS3 / JavaScript
- 국토교통부 브이월드(V-World) 지도 API
- OpenLayers
- GitHub Pages
